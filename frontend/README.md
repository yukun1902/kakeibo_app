# おかねノート（フロントエンド）

HTML・CSS・JavaScript で作った、支出を記録する家計簿アプリの画面です。
データは Go の REST API（`../main.go`）を通して PostgreSQL に保存します。

## 開き方

1. `kakeibo_app` フォルダで `go run .` を実行してサーバーを起動する
2. ブラウザで `http://localhost:8080` を開く（Go のサーバーがこのフォルダを配信している）
3. ログイン画面が出るので、「新規登録」からメールアドレスとパスワードを登録する

`index.html` をファイルとして直接開いた場合も、`http://localhost:8080` のサーバーにつながります（サーバーの起動は必要）。

## スマートフォン専用

- スマホの画面いっぱいに表示します（ノッチやホームバーの部分も考慮済み）
- PC で開くと「スマートフォン専用です」の案内が出ます。
  「PCでプレビューする」を押すと、スマホの大きさで表示されます（タブを閉じるまで有効）
- 開発中は Chrome / Edge の開発者ツール（F12）→ デバイスツールバー（Ctrl+Shift+M）で
  スマホ表示にして確認するのがおすすめです
- http(s) で配信すると、スマホの「ホーム画面に追加」でアプリのように全画面で開けます（`manifest.webmanifest`）

## ファイル構成

```
frontend/
├── index.html           … 入口
├── manifest.webmanifest … ホーム画面に追加したときの設定
├── icon.svg             … アプリのアイコン
├── css/style.css        … 見た目（ライト/ダークテーマ対応）
└── js/
    ├── api.js           … データ層（Go の REST API を fetch で呼ぶ・ログインの JWT を管理）
    └── app.js           … 画面の表示と画面遷移
```

## ログインのしくみ

- ログインすると API から JWT（24時間有効）を受け取り、ブラウザ（localStorage）に保存する
- API を呼ぶときは、毎回 `Authorization: Bearer <JWT>` を付ける
- API が 401（期限切れなど）を返したら、保存している JWT を消してログイン画面に戻す
- ログアウトは、ブラウザに保存している JWT を消すだけ

## データの形

```jsonc
// categories
{ "id": 1, "name": "食費" }

// expenses（memo は空なら null）
{
  "id": 1, "category_id": 1, "amount": 1200,
  "date": "2026-10-14", "memo": "スーパー", "created_at": "2026-10-14T14:35:00"
}
```

カテゴリーのアイコンと色は DB に保存せず、画面側（`app.js` の `styleOf`）で決めています。
最初から用意しているカテゴリーは名前で決まり、それ以外は名前の1文字目をアイコンにして、色は ID から選びます。

API の一覧は [../README.md](../README.md) を見てください。
